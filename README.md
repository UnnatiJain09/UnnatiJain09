## The project I'm proudest of

### [SaaS Project Management Tool](https://github.com/UnnatiJain09/saas-pm-tool)
A Trello-meets-Jira style app where every team gets its own isolated workspace.

- Kanban boards with drag-and-drop, a calendar view, file attachments, and in-app notifications
- Four roles (Owner / Admin / Member / Viewer), checked on every API route through one reusable function
- Stripe subscriptions with signature-verified webhooks and plan-based feature gating
- **Choices I made on purpose:** every query is scoped by workspace so tenants can't see each other's data, and notifications use polling instead of WebSockets because sockets are painful on serverless hosting

**Stack:** Next.js, TypeScript, Prisma, PostgreSQL, Stripe, Tailwind
